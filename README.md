# Fake Job Detection

## 📌 Project Overview

Fake job postings are becoming a common problem for students and job seekers. Some fraudulent job postings may try to collect personal information, demand money, or mislead candidates.

**Fake Job Detection** is a web application that helps users identify potentially fake job postings by analyzing the information provided in a job description.

## 🎯 Problem Statement

It can be difficult for job seekers to determine whether an online job posting is genuine or fraudulent just by reading it.

This project provides an additional way to evaluate a job posting by analyzing its textual content and predicting whether it is likely to be **genuine or fake**.

## 💡 How It Works

1. The user enters the details of a job posting.
2. The system processes the job description.
3. The text is converted into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)**.
4. A machine-learning model analyzes the processed information.
5. The system displays the prediction to the user.
